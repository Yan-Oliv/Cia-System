# Cia System (build web)

Build **Flutter Web** do *Cia System*, o sistema interno criado para organizar a operação logística da Cia Cargas.

Este repositório contém somente os artefatos publicados; o código-fonte é privado. A evolução do sistema deu origem ao **OmnyaLog** ([log.omnyatech.com.br](https://log.omnyatech.com.br/)).
